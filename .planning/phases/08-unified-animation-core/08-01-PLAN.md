  <files>src/types/avatar.ts, src/lipsync/face-controller.ts</files>
  <action>
    1. W `src/types/avatar.ts` dodaj kontrakt v2 z 08-CONTEXT:
    ```ts
    export interface PoseFrame { timeSec: number; weights: Record<string, number>; }
    export interface FramesClip {
      frames: PoseFrame[];
      fps: number;
      shapes: string[];
      carriesEyes: boolean;
      carriesEmotion: boolean;
      emotions?: Array<{ timeSec: number; weights: Record<string, number> }>;
    }
    export type AnimationMode = 'viseme' | 'frames';
    ```
    2. W `FaceController`:
       - pole `private animationMode: AnimationMode = 'viseme';` + `private pendingMode: AnimationMode | null = null;`
       - `public setAnimationMode(mode: AnimationMode, opts?: { deferToTurnEnd?: boolean }): void`
         — bez flagi: natychmiast (dev-switch): `this.scheduler.clear(); this.frameBuffer = [];
         this.resetSpeechWeights(); clearManualOverrides(); state → IDLE` (jak dotychczas).
         Z `deferToTurnEnd: true`: zapis `pendingMode` — zastosowane na granicy tury
         (przejście do RELAXING/IDLE) lub w `onInterruption()` (po wyczyszczeniu).
       - getter `public getAnimationMode(): AnimationMode`
    3. Uwaga kompatybilności: domyślny tryb `viseme` — istniejące zachowanie bez zmian (regresja).
  </action>

<task type="auto">
  <name>Task 2: Bufor ramek + aplikacja bezwzględna w render (kontrakt v2)</name>
  <files>src/lipsync/face-controller.ts, tests/animation-frames.test.ts</files>
  <action>
    1. Pola: `private frameBuffer: PoseFrame[] = [];` (posortowane rosnąco — sort przy podaniu),
       `private frameBaseSec = 0;`, `private frameMeta: FramesClip['shapes'] & flags` —
       przechowaj `shapes`, `carriesEyes`, `carriesEmotion` z clipu.
    2. `public feedFrames(clip: FramesClip, baseSec: number, epoch: number): void`:
       - ignoruj gdy `epoch !== this.engine.getEpoch()` (stara epoka),
       - przejdź do `SPEAKING` (jak onAudioChunk), `clearManualOverrides()`,
       - `this.frameBaseSec = baseSec`; `this.frameBuffer = [...clip.frames].sort((a,b)=>a.timeSec-b.timeSec)`;
         zapisz meta clipu. **timeSec pozostaje RELATYWNY — NIE dodawaj tu bazy!**
    3. W `render(dt)`, gdy `animationMode === 'frames'`:
       - `now = engine.ctx.currentTime`; ramka ważna gdy `frameBaseSec + timeSec <= now`,
       - usuń ramki `frameBaseSec + timeSec < now - 0.05` (przeterminowane),
       - znajdź bieżącą (binarnie); aplikuj `applyWeight(shape, w)` dla każdego wpisu;
         **ZAPISUJ też `this.currentWeights.set(shape, w)`** (RELAXING musi interpolować
         z ostatniej pozy!),
       - safety po aplikacji ramki: clamp 0..1, `mouthClose = min(w, 0.85)`
         (CLOSE_SAFETY_CAP — jak w VisemeScheduler), guard jaw-vs-close,
       - kształty z `clip.shapes`, których brak w bieżącej ramce → wyzeruj (to zastępuje
         heurystykę ">10 kluczy"; brak kształtu w ramce = świadome 0),
       - EmotionLayer: gdy `carriesEmotion === true` → NIE dodawaj 30% emocji do wag mowy
         w SPEAKING (ramki niosą własną ekspresję A2E); IDLE/RELAXING — bez zmian,
       - jeśli `frameBuffer` pusty i `!engine.hasPendingAudio()` → RELAXING (jak w viseme),
       - NIE uruchamiaj `ProceduralBlink` gdy `carriesEyes === true`; blinkProvider pomijany
         tylko dla tej kategorii (jeśli clip nie niesie oczu — blink zostaje).
    4. Dostosuj istniejący `render`: blok mrugania warunkowo; `GazeSaccades` piszące
       `eyeLook*` omijamy gdy tryb frames + carriesEyes (main.ts — patrz 08-03).
    5. Testy w `tests/animation-frames.test.ts` (reuse fake driver/engine):
       - feedFrames z clipem 3 ramek [0, 0.5, 1.0] relatywnych + baseSec → render na środkowej
         ramce aplikuje dokładnie jej wektor (jawOpen = wartość ramki),
       - RELAXING po wyczerpaniu ramek startuje z wartości OSTATNIEJ ramki (currentWeights),
       - ramka z mouthClose = 1.0 → efektywnie 0.85 na driverze,
       - brak klucza z clip.shapes w ramce → wyzerowany,
       - feedFrames starej epoki → ignorowane; carriesEyes=true → brak wpisów eyeBlink*,
       - carriesEmotion=true → waga mowy nie zawiera komponentu emocji.
  </action>
