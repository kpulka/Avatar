### Technical decisions (locked)
- **D-1 Demo speech = recorded TTS + real alignment.** The 140/280/420 Hz tone (`speech-backend.ts:303-353`)
  looks mechanical. A clip generated once with ElevenLabs *text-to-speech with timestamps* gives real audio and
  exact character timings. Assets: `public/demo/demo-hello.wav` (PCM16 mono) + `public/demo/demo-hello.json`
  (`{ text, sampleRate, alignment: { chars, char_start_times_ms, char_durations_ms } }`). Playback goes through
  the SAME path as live speech (`audioEngine.playChunk` → `onAudioChunk(..., sampleRate)` → `audio:chunk`), so
  lip-sync, captions (`transcript:agent`), EmotionLayer and the A/B buffer all work for free.
- **D-2 WAV is parsed by hand, not `decodeAudioData`.** `decodeAudioData` resamples to the context rate and
  returns Float32; the pipeline wants Int16 PCM at the clip's own rate (same as WSS chunks).
- **D-3 Fail loudly, once.** Mic denied → start() rejects, WSS not opened, state `idle`, one error toast.
  WSS: max 5 reconnect attempts, policy/auth close codes (1008, 4000–4999) are not retried; then `disconnected`
  + one toast. Error toasts already stay until closed (toast.ts) — do not add auto-hide.
- **D-4 SSS uses an explicit key-light uniform.** In three r174 `#include <lights_fragment_begin>` leaves the
  variable `directLight` holding the LAST directional light of the loop (here the rim light behind the head,
  `lighting.ts:40-41`), so the current SSS term is ≈0 on the face. Fix: shared uniforms `uKeyLightDirView`
  (key light direction in VIEW space — `directLight.direction` in three's shaders is view space) and
  `uKeyLightColor` (color × intensity), updated once per frame from `Scene.onBeforeRender(renderer, scene, camera)`.
- **D-5 Shadow frustum follows the head.** `keyLight.target` at `(0, faceY, 0)`; key position = target + the
  original offset `(1.5, 2.0, 2.0)` (direction unchanged → look unchanged); orthographic frustum ±0.35 m;
  `normalBias = 0.01`; no-op `shadow.radius` removed (PCFSoftShadowMap ignores it).
- **D-6 Audible clock.** Mouth timing compares scheduled times against the time currently *heard*, not
  `ctx.currentTime` (render position). `getAudibleTime(ctx)` prefers `ctx.getOutputTimestamp()`, falls back to
  `currentTime - (outputLatency || 0) - (baseLatency || 0)`. The stored `syncOffsetMs` presets (90/100/120) were
  a hand-tuned stand-in for that latency → reduced to a small residual and migrated once.
- **D-7 Bilabials close with press + roll, not mouthClose.** On MetaPerson a high `mouthClose` drags the lower lip
  over the upper lip toward the nose (`calibration.ts:38` comment, UAT history) — so `closeScale` stays low and
  closure is built from `jawOpen≈0`, `mouthPressLeft/Right`, `mouthRollLower/Upper`, small `mouthClose`.
- **D-8 Eyes/lashes/hair:** eyeball keeps the GLB `normalMap`/`roughnessMap`; the opacity-0 cornea mesh is hidden
  (`visible = false`, it renders nothing today but costs a transparent draw); lashes + hair use
  `alphaToCoverage: true` with `transparent: false` (MSAA is on — `renderer.ts:13 antialias: true`), which removes
  sorting artefacts.
- **D-9 Softbox IBL** replaces `RoomEnvironment` (generic room → flat reflections); built once into PMREM
  (zero per-frame cost). `Scene.environmentIntensity` (three ≥ r163) tunes it.
- **D-10 Adaptive resolution** is a pure, unit-tested state machine fed by the existing 500 ms FPS window
  (`container.ts:289-297`): FPS < 50 for ≥ 2 s → pixelRatio −0.25 (floor 1.0); FPS > 58 for ≥ 4 s → +0.25 (cap
  `min(devicePixelRatio, 2)`); 3 s hold after every change.
