# Plan 18-02: LICENSE + THIRD-PARTY-NOTICES + CONTRIBUTING

## Goal

Give the repo a license (MIT, owner-confirmed), an evidence-backed third-party notice,
and a contributing guide — the legal-credibility layer. **Owner confirmation of the
license choice is a precondition** (D2 recommends MIT; the ask is bundled with D4/D6 at
phase start per 18-CONTEXT §6.5).

## Requirements

QUAL-03 (license + notices), QUAL-04 (contributing).

## Files

- `LICENSE` — NEW (MIT, copyright holder + year per owner)
- `THIRD-PARTY-NOTICES.md` — NEW
- `CONTRIBUTING.md` — NEW
- `README.md` — fill the license slot (13-01's comment carries the exact text)

## Tasks

1. Confirm with the owner: MIT + the copyright line (name/handle, year 2026). If the
   owner picks a different license, verify compatibility against §1.2's audit before
   proceeding (all-permissive tree → MIT/BSD-2/Apache-2.0 all fine; GPL would create a
   mismatch with nothing — the deps allow it, but the *portfolio intent* argues
   permissive).
2. Write `LICENSE` (standard MIT text verbatim).
3. `THIRD-PARTY-NOTICES.md`: the table from 18-CONTEXT §1.2 — direct deps + license +
   the transitive statement ("all transitive packages in package-lock.json declare
   permissive licenses; audit date 2026-11-18; re-audit command: `Select-String
   package-lock.json '"license":'`"), plus the vendored-blob note (`a2f/sdk` = NVIDIA
   MIT-licensed SDK, not distributed by this repo — gitignored; `a2f/.venv` same).
4. `CONTRIBUTING.md` (short, honest): prerequisites (Node 20+), setup + the four
   commands (install/dev/test/typecheck), the gates a PR must pass (CI: typecheck, test
   incl. language/layering gates, build, lint), how this repo is actually run (GSD
   pointer to `.planning/README.md`), PR expectations (green CI, focused commits,
   English), and "what NOT to commit" (a2f/sdk, .venv, .env, models beyond avatar.glb
   without discussion).
5. Fill the README license slot + badge (18-02 marker in 13-01's placeholder comment);
   language gate stays green.
6. Commit: `chore(license): MIT + third-party notices; docs: CONTRIBUTING`.
