## Test/verification strategy

`npm run verify` is itself the verification artifact; CI running the same pipeline on a
clean checkout is the public proof.

## Risks & mitigations

| Risk | Mitigation |
|---|---|
| Umbrella masks which gate failed (bad DX) | npm's `&&` chain stops at first failure with its exit code — each step's name is in the output; document that behavior in README's details block |
| Close-out prep drifts into actually closing the milestone | Hard boundary: this plan PREPARES, `/gsd-complete-milestone` executes (the repo's own convention for archival + Validated statuses) |
