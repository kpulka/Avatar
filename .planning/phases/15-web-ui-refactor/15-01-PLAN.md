# Plan 15-01: Design tokens, complete theming, typography floor & CSS hygiene

## Goal

Replace the ad-hoc CSS (1,229 lines, 150 raw hex literals, 23 sub-12px font sizes, ~120 dead
lines) with a custom-property token system per `15-DRAFT-ui-spec.md` §2, make the light theme
actually complete (currently 6 container overrides leave dark controls on light glass),
enforce the 12px typography floor and ≥36px interactive targets, and delete dead rules.
Pure CSS work + one regression test — zero TS behavior change.

## Requirements

UIX-01 (tokens & theming), UIX-02 (typography & targets), UIX-11 (CSS hygiene).

## Files

- `src/style.css` — the whole pass
- `tests/ui-tokens.test.ts` — NEW regression gate (node fs read of style.css)

## Tasks

1. Add the token block at the top of `src/style.css` under a `/* ===== 0. TOKENS ===== */`
   TOC section: `:root { … }` defining exactly the tokens from `15-DRAFT-ui-spec.md` §2.1
   (color, surface, border, text, accent, destructive, 4 state colors, spacing `--space-1..8`,
   type roles `--text-display/heading/body/label/mono`, radii `--radius-sm/md/lg/pill`,
   shadows, z-scale `--z-*`, motion `--motion-fast/--motion-panel`).
2. Rewrite every rule that currently hardcodes a color to consume the matching token
   (`background: var(--surface-ctrl)`, `border-color: var(--border-subtle)`, …). After this
   task the ONLY hex/rgba literals allowed in the file are inside the `:root` and
   `body.theme-light` token blocks.
3. Replace the per-component `body.theme-light …` overrides (style.css:879-896, 1043-1052,
   1182-1191 today) with ONE `body.theme-light { … }` block that re-defines tokens only
   (per UI-SPEC §2.2). Delete the component-level light rules.
4. Fix the hardcoded dark controls so the light theme is readable: `.engine-select`,
   `.viseme-group-select`, `.viseme-chip` (style.css:900-914), `.search-input` (416-429),
   `.text-input` (762-774), `.toast` (784-801), `dialog.settings-dialog` (728-742),
   `.btn-subtle`, `.btn-danger-subtle`, `.dock-icon-btn` — all via tokens (falls out of
   task 2/3; verify each in the acceptance checklist).
5. Fix the `#f0c` magenta typo on `.btn-danger` (style.css:924) → `var(--destructive)`.
6. Typography floor: normalize every `font-size: 9/10/11px` (23 declarations) to 12px
   (`--text-label`); delete dead ones with their rules (task 8). `.status-pill` 10px → 12px.
   Apply the four type roles: Display 28/600, Heading 18/600, Body 14/400, Label 12/600;
   `.drawer-header h3` and `.dialog-header h3` become Heading; `.section-title` stays
   Label with uppercase+letterspacing.
7. Targets: `.dock-btn` `min-height: 40px` + `padding: var(--space-2) var(--space-4)`;
   `.dock-icon-btn`/`.user-settings-btn` `min-width/height: 40px`; `.segment-btn`
   `min-height: 40px`; `.studio-tab` `min-height: 36px` (already), `.text-input`,
   `.engine-select`, `.search-input`, `.select` controls `min-height: 36px`;
   `.viseme-chip` `min-height: 28px` (non-primary chip, exempt from 36 but must be ≥28).
8. Delete dead rules (verified zero TS/HTML references in 15-CONTEXT §3.5 C1):
   `.top-dock` + `.dock-left/.dock-center/.dock-right` + `.brand` (36-71),
   `.telemetry-pill-card` + `.pill-header/.pill-label/.pill-val/.pill-fps-badge/.fps-unit/
   .pill-meta/.pill-buttons` (213-279), `.status-idle/.status-loading/.status-ready/
   .status-error` (300-303), `.align-badge/.align-el/.align-fallback` (305-315),
   `.modal-buttons` (776-781), `.select-input` (762), `.btn-presentation:hover` (205-208);
   strip `.top-dock`/`.telemetry-pill-card` from the presentation-mode (681-688) and
   theme-light (883-889) selectors.
9. Z-scale: assign every `z-index` from the documented `--z-*` list (UI-SPEC §2.5). Loader
   becomes `--z-loader` (60) so it renders ABOVE the dock (fixes half of finding S2; the
   CSS half — positioning overlap is resolved in 15-05 task 8).
10. Dedupe the repeated glass recipe by value: the 6 glass surfaces
    (`.transcript-box`, `.user-dock`, `.user-status`, `.user-algo`, `.side-drawer`,
    `dialog.settings-dialog`) all consume `var(--surface*)`, `var(--border-subtle)`,
    `var(--radius-*)`, `var(--shadow-*)`. Keep selectors as-is (class-level dedupe happens
    when 15-03/15-05 touch the TS). Replace every `transition: all …` with named
    properties (`transition: background-color .15s ease, border-color .15s ease, …`).
11. Add the `user-select` opt-out: `body { user-select: none }` stays, but
    `.transcript-text, .loader-text, .drawer-subtitle, .viseme-hint { user-select: text }`.
12. Write `tests/ui-tokens.test.ts` (node fs on `src/style.css`) asserting: (a) `:root` block

    tokens; (e) dead selectors from task 8 are absent.

- Manual: dark+light screenshot matrix (12 surfaces × 2 themes) — feed into Phase 13 pool.

## Risks & mitigations

| Risk | Mitigation |
|---|---|
| Token sweep breaks a visually-tuned surface (glass opacities) | Keep a 1:1 mapping from the literal values found in 15-CONTEXT §3.1 into tokens — no "improvements", only consolidation; verify per-surface screenshots |
| Light theme reveals new contrast failures on controls not previously themed | UI-SPEC §2.2 lists every override; acceptance checklist walks all 12 surfaces in light mode |
| Removing "dead" CSS that some future string uses | Class list verified by per-class grep TODAY; if a class resurfaces, git revert of the deletion hunk is trivial |
