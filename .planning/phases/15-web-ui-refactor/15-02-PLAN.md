# Plan 15-02: Microcopy slot registry (`src/app/copy.ts`) + full retrofit

## Goal

Move every user-visible string (inventory: 15-CONTEXT §4.3, ~120 slots) into one pure,
DOM-free registry so Phase 12 (English-ization) is a value-swap in ONE file. This plan
retrofits all modules to `t()` with ZERO copy changes (Polish values stay Polish — English
is Phase 12's job). Slots defined here are the frozen contract between phases.

## Requirements

UIX-09. Phase 12 depends on this plan's artifacts.

## Files

See frontmatter `files_modified`. New: `src/app/copy.ts`, `tests/copy.test.ts`.

## Tasks

1. Create `src/app/copy.ts` (pure data, no DOM, no imports from `ui/`):
   - `export const COPY: Readonly<Record<string, string>>` — one entry per slot from
     15-CONTEXT §4.3 (use exactly those slot IDs; `{x}` interpolation markers where the
     table marks them).
   - `export function t(slot: string, params?: Record<string, string | number>): string` —
     resolves the slot; unknown slot → `console.warn` + return the slot id (fail-soft);
     replaces `{key}` occurrences with `params[key]`.
2. Move the WebGL fallback card markup out of `index.html:14-27` into
   `src/ui/webgl-fallback.ts`: build the card with `el()` + `t('webgl.*')`, `role="alert"`,
   `aria-labelledby` pointing at the card heading; `handleWebGLFailure()` renders into a
   `#webgl-fallback` mount that `index.html` keeps as an empty `<div id="webgl-fallback">`
   (inside `#app`, after the canvas). Copy strings `webgl.title/body/subtext/fallbackBtn`
   from the index.html values verbatim.
3. Retrofit user layer (import `t` from `../../app/copy`): `status-pill.ts` (brand + 4 state
   labels + title/aria), `conversation-dock.ts` (all button labels + aria labels +
   running-state flips), `captions.ts` (speaker tags + placeholder), `algorithm-switcher.ts`
   (segment aria, compare/blind labels, empty/playing/result/partial/cancelled copy —
   keep current text 1:1, slots per §4.3), `user-settings.ts` (title, all form labels,
   options, lock tooltip `settings.lockTooltip` with `{key}`), `loader.ts` (default + model
   texts).
4. Retrofit `container.ts`: presentation button text/aria, `boot.loadingModel` string.
5. Retrofit studio shell + registry: `studio.title/subtitle/tabsAria/closeAria/
   leftOpenAria/leftCloseAria` (`{panel}`), `panel.errorTitle` (`{title}`) + `panel.retry`.
   Panel titles/icons remain as-is (they are DATA in PanelDefinition, not copy slots — leave
   them; Phase 12 can map them if it wants).
6. Retrofit panels: `animation-panel` (all section titles, slider labels, preset labels,
   button texts, toasts — 9+ slots), `visemes-panel` (toolbar, chips states, resets, hint),
   `inspector-panel` (search placeholder, reset, mirror, 5 category titles, 51 shape
   labels), `a2f-panel` (URL title/placeholder/save/invalid/saved, status copy, demo, stats),
   `session-panel` (agent, audio, telemetry labels, align copy, locks, profile I/O, stress),
   `scene-panel` (model info, demo, GLB, presets, hint).
   Slider labels (animation ×9, viseme shapes ×11) and inspector shape labels (×51) are
   STATIC per-key data: give each a slot (`animation.slider.jawOpen` etc.) so Phase 12 can
   translate them without touching logic.
7. Retrofit features-layer toast strings (cross-seam flagged for Phase 14 review, 15-CONTEXT
   §5.1): `conversation-controller.ts` toast/poc slots, `compare-controller.ts` failure +
   a2f-down slots — import `t` from `../app/copy` (pure module, legal direction).
   IMPORTANT: do NOT delete any toast here — de-spam is 15-05.
8. Write `tests/copy.test.ts`: (a) every slot in a canonical list (assert COPY key count
   matches §4.3 count) resolves non-empty; (b) `t()` unknown slot warns + returns id;
   (c) interpolation `t('algo.resultPredictMs', {ms: 1234})` → `predict 1234 ms`;
   (d) static gate: `src/ui/**` and `index.html` contain no Polish diacritics
   (`[ąćęłńóśźż]`) OUTSIDE `src/app/copy.ts` — this is the enforcement that no inline string
   escapes the registry (Phase 12 keeps it green trivially).
9. Run the diacritics check NOW — it will fail on features-layer if step 7 missed a string;
   fix until green (danish-poli unicode included: `ąćęłńóśźż`).

- New `tests/copy.test.ts` — slot resolution, warn behavior, interpolation, diacritics gate.
- Manual smoke: user layer + studio render identically to pre-plan (strings only relocated).
- Phase 12 handoff = this plan's slot table; note in 15-VERIFICATION §6.

## Risks & mitigations

| Risk | Mitigation |
|---|---|
| Features-layer strings (toast) violate the "UI never imports from ui/" layering | `src/app/copy.ts` lives in `app/` (pure) so both layers import DOWN legally; Phase 14 review flagged in CONTEXT §7.3 |
| A string is missed → diacritics gate fails late | Gate is a unit test; fix loop in-task, not after the fact |
| Phase 12 wants strings that live in data tables (panel titles) | Those stay in PanelDefinition; document the boundary in 15-VERIFICATION §6 so Phase 12 knows to check both |
