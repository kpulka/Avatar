Purpose: Umożliwienie użytkownikowi płynnego mówienia do awatara zgodnie z polityką przeglądarek dot. AudioContext.
Output: Kompletny pipeline wejścia audio (Microphone -> Resampler -> PCM 16kHz -> Base64).

<context>
Agent wymaga chunków PCM 16 kHz mono, 16-bit little endian, spakowanych do base64 w wiadomości `{ "user_audio_chunk": "..." }`.
Browser AudioContext domyślnie działa w 44.1 kHz lub 48 kHz — wymagany jest precyzyjny resampler w locie.
</context>
