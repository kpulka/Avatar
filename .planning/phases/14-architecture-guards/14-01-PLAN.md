# Plan 14-01: Full-project typecheck + zero `any`

## Goal

Close both strictness holes: every line of `src` **and** `tests` type-checks in one command
(`npm run typecheck`), `noUncheckedIndexedAccess` is on, and the 3 surviving `any` casts
are typed away — so the "rigorous TypeScript" story is true for the whole repo, not just
the build path.

## Requirements

ARCH-02 (full-project typecheck, flag adoption, zero `any`).

## Files

- `tsconfig.json` — add `noUncheckedIndexedAccess: true` (base flags otherwise unchanged)
- `tsconfig.test.json` — NEW: extends base, `include: ["src", "tests"]`
- `package.json` — add `"typecheck": "tsc --noEmit -p tsconfig.test.json"`
- The 3 cast sites from 14-CONTEXT §1.4 + any files `noUncheckedIndexedAccess` flags

   - `meta-person-loader.ts:53` — type the morph-name key so `REQUIRED_SHAPES.includes(k)`
