  <name>Task 2: Merge czasu — fonemy z kotwic alignmentu znaków</name>
  <files>src/lipsync/g2p/phoneme-merge.ts, tests/phoneme-merge.test.ts</files>
  <action>
    Utwórz `src/lipsync/g2p/phoneme-merge.ts`:
    ```ts
    export interface PhonemeSpan { phoneme: string; startMs: number; durationMs: number; }
    export function mergeCharAlignmentToPhonemes(alignment: CharAlignment): PhonemeSpan[]
    ```
    Algorytm (deterministyczny):
    1. Jeśli `alignment.source` istnieje i ≠ `'elevenlabs'` → zwróć `[]` (fallback energii
       obsługuje FaceController; nie ma tekstu do konwersji).
    2. Tokenizacja: iteruj po `alignment.chars`; **run liter** (regex `[A-Za-z'’-]+`) = słowo;
       wszystko inne (spacje, interpunkcja, cyfry) = granica. Zapamiętuj indeksy pierwszego
       i ostatniego znaku słowa.
    3. Dla każdego słowa:
       - `wordStartMs = char_start_times_ms[firstIdx]`, `wordEndMs = char_start_times_ms[lastIdx] + char_durations_ms[lastIdx]`
       - `phonemes = wordToPhonemesSync(word)` — puste/null → pomiń słowo.
       - Rozkład czasu: waga fonemu = 1.2 dla samogłosek/dyftongów
         (zbiór: AA AH AE AO AW AY EH ER EY IH IY OW OY UH UW), 0.8 dla spółgłosek.
         `totalWeight = Σ wag`; `dur_i = (wordEndMs - wordStartMs) × weight_i / totalWeight`;
         `start_i` kaskadowo od `wordStartMs`. Durację min 35 ms.
    4. Wyjście: wszystkie spans słów w kolejności wystąpienia.
    `tests/phoneme-merge.test.ts`:
    - Fixture: "know what" jako chars z równymi czasami per znak (np. 100 ms/znak):
      → 'know' daje dokładnie 2 spans (N, OW — brak K!), pierwszy startuje na starcie słowa,
      ostatni kończy się na końcu słowa (suma duracji = długość słowa ± zaokrąglenia)
    - Spacja i 'w'...'what' — 'what' → [W,AH,T] (3 spans; WH wymawiane jako W — realny wpis CMUdict to "W AH1 T")
    - `source: 'energy-fallback'` → `[]`
    - Interpunkcja ('.', ',') nie produkuje spanów

      g2pAvailable() &&

      (alignment.source === undefined || alignment.source === 'elevenlabs');
    if (usePhonemes) {
      const spans = mergeCharAlignmentToPhonemes(alignment);
      if (spans.length > 0) {
        const profile = this.scheduler.getCalibrationProfile();
        const syncOffsetSec = profile.syncOffsetMs / 1000;
        for (const span of spans) {
          const shapes = mapPhonemeToShapes(span.phoneme);
          if (!shapes) continue; // nieznany fonem → brak wizemy
          this.scheduler.enqueue({
            epoch,
            char: span.phoneme,
            shapes,
            startTimeSec: chunkStartTimeSec + span.startMs / 1000 + syncOffsetSec,
            durationSec: Math.max(0.035, span.durationMs / 1000),
          });
