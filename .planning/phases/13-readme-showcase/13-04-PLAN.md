# Plan 13-04: Docs truthfulness sweep + retrospective (roadmap convention)

## Goal

Extend the README's honesty standard to the docs a deep-diving reviewer opens next, then
close Phase 13 with the roadmap convention: verify goal-backward, extract learnings,
wire the staleness-prevention hooks into sibling phases.

## Requirements

READ-02 (docs side of truthfulness).

## Files

- `docs/0-roadmap-poc-mvp.md` — status corrections (content edits are 12-02's lane;
  these are *factual status* fixes only, sequenced after 12's translation waves)
- `14-VERIFICATION`-style close-out for this phase + ROADMAP/STATE

## Tasks

1. **Truthfulness sweep over docs/** (after 12's translation waves landed — the sweep
   reads the English docs): for each doc, check its "current state" claims against the
   tree. Known targets:
   - `docs/0` — the PoC/MVP acceptance criteria are met (phases 4/6 checklists) but the
     doc likely still reads as a *plan*; add a short "Status: PoC + MVP complete
     (2026-09), v1. in flight" preamble — no restructure.
   - Stale "Faza 2" phrasing anywhere it implies the current milestone (v2 EXP backlog
     is the accurate frame — REQUIREMENTS.md already says this).
   - `a2f/README.md` — status of the local environment (built engines? blocked OOM?)
     must match STATE.md blockers, not a rosier memory.
   - Anything the sweep finds goes in a findings table in SUMMARY: claim → reality →
     fix applied / owner if it's another phase's file.
2. **Staleness hooks** (R-1 mitigation made structural): add one line to each sibling
   phase's retro task list (via the orchestrator, not by editing their files): "README
   rows affected by this phase? → update the row + its Verified date." Phases 15–18 all
   have at least one row.
3. **Retrospective** (goal-backward): the phase goal was "a README a reviewer can scan
   in 30 seconds and trust on every line". Test: read the final README cold; list every
   sentence that *could* rot and confirm it either carries a Verified stamp, links a
   living source, or is stable by nature. Record the honest residual risk.
4. Execute `13-VERIFICATION.md` (automated gates + the human scan pending), fill the
   verdict, update ROADMAP (phase 13 block + progress) and STATE.

## Acceptance criteria

- [ ] docs/0 status preamble added; sweep findings table in SUMMARY with dispositions
- [ ] Staleness hooks recorded for phases 15–18 retros (orchestrator-confirmed)

## Test/verification strategy

The sweep is manual-by-nature but evidence-logged (claim → reality pairs); the language
and link gates cover mechanical integrity of any edited doc.
