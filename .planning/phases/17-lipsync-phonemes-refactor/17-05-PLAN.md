# 17-05: Quality harness — live UAT protocol (manual, scripted, recorded)

## Goal

Turn lip-sync quality from "judged by eye in a demo" into a repeatable protocol whose
results are recorded — one session closes this phase's UAT AND the long-pending 07-04.

## Requirements

LIP-07 (UAT part).

## Files

- `17-UAT-PROTOCOL.md` (new — the protocol document)
- `17-VERIFICATION.md` (filled with results at execution)

## Tasks

1. **Write `17-UAT-PROTOCOL.md`** with these scripted sections (each item: how to trigger,
   what to observe, PASS/FAIL criterion, and where the trigger data lives):
   - **Setup**: dev server, model loaded, agent connected (or LastTurnBuffer replay for
     offline items — the phase-11 compare path replays known PCM+alignment), telemetry HUD
     on (Studio → Session), FPS visible.
   - **§1 EN closures (LIPS-06/07-04)**: sentences rich in M/B/P (from en-visemes §6);
     criterion: full visible closure on every bilabial, effective mouthClose badge ≥ 0.85
     when the inspector is open on `mouthClose`.
   - **§2 EN silent letters (LIPS-05)**: "know", "though", "listen", "island", "question";
     criterion: no mouth motion during the silent portion (watch in slow-mo via frames
     replay if available).
   - **§3 Twin distinctness**: S vs SH, O vs U, A vs E pairs in sentences; criterion:
     visually distinguishable poses (this is where the EH/AE smile-twin question from
     17-CONTEXT §A.6 gets its verdict — record the verdict either way).
   - **§4 PL digraphs (17-04)**: `szczypczyzna`, `dziękuję`, `chata`, `ziarno`, `trzeba`
     on the phoneme-pl path; criterion: sharp SZ/CZ, soft DŹ, H-like CH, no false softness.
   - **§5 30 s drift**: long utterance (read-aloud paragraph); criterion: alignment ratio
     telemetry within ±10% post-rescale, no cumulative lip-audio offset by the end.
   - **§6 Barge-in**: 10 interruptions at random points; criterion: audio stop
     imperceptible-lag, face neutral < 300 ms, 10/10 (CONV-04 re-validation).
   - **§7 Fallback honesty (LIP-06)**: force fallback (alignment-stripped replay);
     criterion: jaw-only motion, no fake vowels, degradation chip visible in user mode.
   - **§8 FPS**: ≥ 60 during speech on the reference machine (AVAT-02 spot check).
   - **Recording rule**: every section gets PASS/FAIL + a one-line observation; FAIL
     items become actionable findings with file references, not silent re-runs.
2. **Absorb 07-04**: map each 07-VERIFICATION pending item to a protocol section (badge
   ALIGN check → §7 setup; phoneme/char A/B → §1–§3; drift → §5; barge-in → §6); the
   protocol session's results table marks those items closed in 07-VERIFICATION.md.
3. **Execute the protocol** in a live session (human + agent): fill 17-VERIFICATION.md
   §"UAT results" with the actual table; update 07-VERIFICATION.md cross-references.
4. **Honest failure handling**: any FAIL becomes a finding row (severity, suspected module
   from the 17-CONTEXT evidence map) — the phase can still close PARTIAL with the finding
   tracked; never re-run-to-green without a code change.
