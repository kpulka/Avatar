   beyond types). Keep ALL current behavior: field aliases
   (`alignment`/`normalized_alignment`/`alignments`), `chars`/`characters`, ms and
   seconds units (×1000; `character_end_times_seconds` → durations with 25 ms floor),

   system; length mismatch → null; durations absent → 50 ms flat; end<start (degenerate)
   → null; empty chars → null; realistic EL payload (from docs/2 example) → exact output.
3. **Degradation chip (user mode)**: when a chunk's alignment source is
   `'energy-fallback'`, show a subtle chip near the status pill (copy slot
   `chip.simplifiedLipsync` = "Simplified lip-sync" EN / "Uproszczony lip-sync" PL),
   auto-hide when EL alignment returns for 2+ consecutive chunks. Wire: speech-backend
   already tags `source`; expose a `voice:alignSource` event (or reuse existing telemetry
   counters — pick the lighter seam; document the choice in the SUMMARY). Studio's
   detailed ALIGN badge stays as-is.
4. **Docs sync** (language depends on whether 12 landed — content identical either way):
   - docs/3: pipeline diagram gains the pruned-lexicon node (17-01) and the PL phoneme
     path (17-04); the effective-value layering section (table × preset × 0.85 cap —
     17-CONTEXT L-8) written with the computed example (0.8 × 0.6 = 0.48 → meets the
     MetaPerson-advice range, capped 0.85);
   - docs/en-visemes: stale §4 numbers synced to the v1.3-in-code values (17-02 did the
     reconciliation — this lands the doc edit if 17-02 deferred it); status column for
     §5.5 diphthong motion updated (implemented / tuned-by-harness);
   - `agent_response_correction` semantics (L-11): one paragraph in docs/4's interruption
     section — corrections update captions only; audio/visemes are epoch-invalidated
     (coordinate: 16-07 also edits docs/4 — sequence this plan AFTER 16-07 or merge).
5. Commit: `feat(lipsync): honest fallback (pure normalizer + user chip) + docs sync`.
